# Strand — AI Agency

A concept website for **Strand**, an AI agency that designs, builds and runs AI agents. One continuous line draws itself through every section as you scroll.

**Stack:** React 19 · TypeScript · Vite · GSAP + ScrollTrigger · Lenis

- Scroll-drawn thread that weaves through sections (`src/components/Thread.tsx`, driven by `data-thread` waypoints)
- Light / dark theme with a circular wipe transition
- Variable-font hero, magnetic CTA, custom cursor, preloader
- Fully responsive

```bash
npm install
npm run dev
```

All copy lives in `src/content.ts`; figures marked "sample" are placeholders.
